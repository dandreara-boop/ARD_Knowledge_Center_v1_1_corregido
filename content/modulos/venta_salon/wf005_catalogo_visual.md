# WF-005 — Catálogo Visual de Artículos sin Código

**Estado:** Aprobado  
**Versión:** 1.1  
**Módulo:** Venta en Salón

## Objetivo

Permitir la carga rápida de artículos que no llevan etiqueta individual porque son pequeños, económicos o se venden en grandes cantidades.

## Wireframe aprobado

![WF-005 Catálogo Visual](/static/images/wf005_catalogo_visual_v1_1.png)

## Funcionamiento

```text
Caja de Venta
    ↓
Artículos sin código
    ↓
Catálogo con imágenes
    ↓
Doble clic sobre el artículo
    ↓
Código agregado automáticamente a la venta
```

## Información de cada tarjeta

- Imagen.
- Nombre.
- Código interno.

## Reglas

- El catálogo es configurable.
- El doble clic agrega inmediatamente una unidad.
- El producto puede venderse por código de barras, catálogo visual o ambos.
- La ventana se cierra o permanece abierta según una configuración futura de operación rápida.
- El catálogo no reemplaza la búsqueda general de productos.
