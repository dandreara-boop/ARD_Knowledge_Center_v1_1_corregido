# Modelo de datos — Carga de Productos

## Entidades

### Producto

- Código.
- Descripción.
- Precio.
- Estado.
- Canales.
- Atributos designados.

### Remito de Entrada

- Número.
- Fecha.
- Estado.
- Proveedor.
- Participantes.
- Observaciones.

### Ítem del remito

- Producto.
- Código.
- Costo.
- Estado de carga.
- Observaciones.

### Conteo

- Producto.
- Valores de atributos.
- Cantidad.

### Asignación inicial

- Producto o combinación de atributos.
- Destino.
- Cantidad.

### Movimiento de stock

- Origen.
- Destino.
- Cantidad.
- Motivo.
- Documento.
- Usuario.
- Fecha.
