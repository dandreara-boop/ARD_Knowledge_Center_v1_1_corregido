# Visión y filosofía de ARD Suite

> ARD Suite no nace para adaptar una empresa a un software. Nace para adaptar el software a la forma real de trabajar de una empresa.

## Objetivo general

Construir una plataforma comercial integral para una empresa textil con locales físicos, canal online, administración, stock, facturación, remitos, clientes y asistencia inteligente.

## Principios rectores

- El sistema debe ser una herramienta y no una complicación.
- La velocidad del operador tiene prioridad.
- Las políticas las define la empresa; el operador ejecuta.
- Toda decisión automática debe ser explicable.
- El historial nunca debe perderse.
- La venta local debe continuar aunque no exista Internet.
- La IA vende en la web y sugiere acciones administrativas dentro de reglas claras.

## Orden de puesta en marcha

1. Carga de Productos.
2. Venta en Salón.
3. Administración y operación consolidada.
4. Integración con Tiendanube.
5. Inteligencia comercial.
6. Plataforma web propia.
