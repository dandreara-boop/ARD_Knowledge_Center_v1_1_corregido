# Diccionario del Negocio

| Término | Definición |
|---|---|
| Producto | Identidad comercial del artículo. |
| Atributo | Característica configurable: talle, color, estampa, número. |
| Curva | Conjunto versionable de talles o valores. |
| Variante | Combinación de atributos usada según canal o proceso. |
| Remito de Entrada | Documento colaborativo de carga de mercadería. |
| Destino | Local, depósito, stock web u otro punto operativo. |
| Valor reconocido | Importe que se reconoce para un cambio. |
| Campaña comercial | Regla temporal que modifica la venta sin crear productos nuevos. |
| Cola de sincronización | Operaciones locales pendientes de ser enviadas a la nube. |
